Connection

接続設定（AI・同期）

AI分析とスプレッドシート同期は、同じ Apps Script ウェブアプリを使います。接続情報はこの端末にのみ保存されます（キーはタブを閉じると消えます）。

apps-script/Code.gs をデプロイし、Script Propertiesに API_KEY と GEMINI_API_KEY を設定してください。SPLITAPPと同じ手順です。

ブラウザから直接 Google の API を呼びます。手軽ですが、キーはこの端末のタブ内にのみ保持されます。共有PCでは Apps Script 経由を推奨します。
