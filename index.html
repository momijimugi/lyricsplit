Connection

接続設定（AI・同期）

AI分析とスプレッドシート同期は、同じ Apps Script ウェブアプリを使います。接続情報はこの端末にのみ保存されます（キーはタブを閉じると消えます）。

apps-script/Code.gs をデプロイし、Script Propertiesに API_KEY と GEMINI_API_KEY を設定してください。SPLITAPPと同じ手順です。

ブラウザから直接 Google の API を呼びます。手軽ですが、キーはこの端末のタブ内にのみ保持されます。共有PCでは Apps Script 経由を推奨します。

Import

歌詞を一括入力

空行でセクションを区切ります。行頭の [Aメロ] [サビ] [大サビ] や [Verse 1] [Chorus] からセクション種別を自動判定します（どちらの表記でもOK）。取り込んだ歌詞は現在の作業者の貢献として記録されます。

Help

LYRICLABの使い方

3つの編集モード

編集
行をクリックしてそのまま書き換えます。書いた文字はあなたの貢献として記録されます。
提案
行をクリックして書き換え案を出します。相手が採用したときだけ歌詞に反映され、提案者の貢献になります。
コメント
行やセクションに指摘・質問を残します。歌詞は変わりませんが、推敲への関与としてログに残ります。

貢献パーセンテージの算出

画面上部のバーが現在の比率です。次の3軸を配合して算出しています。データのない軸は自動的に他の軸へ按分されます。

  • 現存する歌詞（55%） — 完成歌詞に今も残っている文字数。セクション比重（サビ×1.5 など）を掛けます。
  • 採用された提案（20%） — 提案して相手が採用した案。
  • 推敲・レビュー関与（25%） — 編集・提案・コメント・レビューといった作業ログの手数。

算出値はあくまで参考値です。最終比率は「スプリット合意」から話し合って決めた数字を保存してください。

提案とコメント

右のパネルで提案の採用・却下ができます。提案カードには質問や意見をコメントでき、コメントには返信できます。未解決のコメントは歌詞プレビューにも表示されます。

歌詞プレビューは既定で提案を反映した状態です。スイッチを切り替えると、いま確定している歌詞だけの「完成形」になります。提案は緑、対案は段数ぶん字下げした青の破線で表示され、行へのコメントと提案へのコメントも並びます。

対案を押すと、その提案にさらに案を重ねられます。下敷きは元の提案文なので、上から読むと推敲の流れになります。どれか1つを採用すると、同じ流れに残った案は「対案で解決」として自動的に閉じます。

セクションと呼び名

セクション種別（Aメロ・サビなど）は貢献の重み付けに使われます。「Aメロ / サビ」と「Verse / Chorus」の呼び名は、案件の編集から切り替えられます。

接続と同期

起動時にまず接続画面が出ます。Apps ScriptウェブアプリのURLと接続キーを入れて接続すると、共作者と歌詞・提案・作業ログを共有できます。接続キーはタブを閉じると消えるため、開くたびに入力が必要です。

「Apps Scriptに接続できませんでした（CORSブロック）」と出る場合は、デプロイの「アクセスできるユーザー」が全員になっているか確認してください。ログインが必要な設定だと、ブラウザからは接続できません。コードを更新したときは、新しいバージョンとしてデプロイし直す必要があります。

接続後はヘッダーの「同期」でいつでも手動同期できます。ピルに 未接続 / 接続済み / 同期中 / 同期エラー / 最終同期時刻 が出ます。接続せずにこの端末だけで使うことも選べますが、その場合は共作者とは共有されません。
